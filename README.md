# Gurugram Real Estate Analysis

## 1. Project Title

**Gurugram Real Estate Analysis**

## 2. Short Description / Purpose

A Python-based exploratory data analysis project focused on understanding property prices, locality-wise pricing, property characteristics, and factors associated with real estate pricing in Gurugram.

The project includes data cleaning, feature preparation, analysis, and data visualization using Python.

## 3. Tech Stack

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## 4. Data Source

The project uses a Gurugram real estate dataset containing information related to:

- Property price
- Area
- Rate per square foot
- Locality
- Flat type
- BHK configuration
- Property status
- RERA approval
- Builder

## 5. Features & Highlights

### Data Cleaning

- Standardized column names
- Removed duplicate records
- Converted price, area, and rate per square foot into numeric values
- Standardized categorical values
- Converted RERA approval status into Boolean values

### Price Analysis

- Identified the costliest flat in the dataset
- Identified the locality with the highest average property price
- Identified the locality with the highest rate per square foot
- Compared ready-to-move and under-construction property prices
- Compared RERA-approved and non-RERA-approved property prices

### Property Analysis

- Analyzed average price by BHK configuration
- Compared pricing across property types
- Analyzed builder-wise average property prices
- Studied the relationship between property area and price
- Studied the relationship between property area and rate per square foot

### Visualizations

- Area vs Price scatter plot
- Area vs Rate per Square Foot scatter plot

## 6. Key Questions

- Which is the costliest flat in the dataset?
- Which locality has the highest average price?
- Which locality has the highest rate per square foot?
- How do ready-to-move and under-construction properties compare in price?
- Does RERA approval correspond with different average property prices?
- How does area impact property price?
- Which BHK configuration has the highest average price?
- Which property type has the highest average price?
- Which builder has the highest average property price?
- Are larger homes more expensive per square foot?
